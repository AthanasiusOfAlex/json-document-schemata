Aquinas Opera Omnia

Opera Omnia S. Thomae Aquinatis

A recursive tree modelling the complete Latin works of Aquinas, harmonising the scholastic method (pars → quaestio → articulus → respondeo) with the typographical boundaries of physical critical editions. Draft-07.

Journal Article

PDFTranscriber — TranscribedDocument

The serialization produced by PDFTranscriber: a transcribed PDF as page metadata plus an ordered array of pages carrying paragraphs, headings, block quotes, and footnotes, with continuation flags for content that spans page breaks. Draft 2020-12.

A small shared schema for canonical bibliographic references, reusable across documents via $ref. Currently unused by the two document schemata.

Using a schema

Each schema's $id is its canonical URL on this site, so you can reference it directly:

{
  "$ref": "https://athanasiusofalex.github.io/json-document-schemata/schemas/journal-article/v1/schema.json"
}

Schemata are versioned by directory (/v1/). A breaking change ships as a new version rather than a silent edit to an existing $id.
